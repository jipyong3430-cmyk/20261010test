JAVASCRIPT BASICS / 02

데이터 타입,
값의 종류를 구분하기

값의 종류에 따라 할 수 있는 연산과 변환 결과가 달라져요. 먼저 자주 쓰는 타입을 눈에 익혀 봅시다.

기본 데이터 타입

자바스크립트의 원시 타입 7가지와 객체 타입의 대표 예시입니다.

숫자 Number

정수와 소수를 모두 표현해요.

const count = 3;
const price = 3.14;
console.log(count + 4); // 7
console.log(price);     // 3.14

문자열 String

글자를 작은따옴표, 큰따옴표 또는 백틱으로 감싸요.

const name = "민지";
const greeting = `안녕, ${name}!`;
console.log(greeting); // 안녕, 민지!

불리언 Boolean

참 또는 거짓을 나타내며 조건문에서 자주 써요.

const isAdult = true;
const hasTicket = false;
console.log(isAdult && hasTicket); // false

정의되지 않음 undefined

값을 아직 할당하지 않은 변수의 기본 상태예요.

let message;
console.log(message);        // undefined
console.log(typeof message); // "undefined"

값이 없음 null

값이 비어 있음을 의도적으로 표시해요.

const selectedItem = null;
console.log(selectedItem); // null
console.log(typeof null);  // "object" (오래된 동작)

큰 정수 BigInt

Number의 안전한 정수 범위를 넘어가는 정수에 사용해요.

const hugeNumber = 9007199254740993n;
console.log(hugeNumber + 2n); // 9007199254740995n
// BigInt와 Number는 바로 더할 수 없어요.

심벌 Symbol

겹치지 않는 고유한 값을 만들 때 사용해요.

const firstId = Symbol("id");
const secondId = Symbol("id");
console.log(firstId === secondId); // false

객체와 배열 Object

여러 값을 묶어요. 배열도 객체 타입에 속해요.

const user = { name: "민지", age: 20 };
const colors = ["초록", "주황"];
console.log(user.name, colors[0]); // 민지 초록

타입 변환하기

원하는 타입 이름을 함수처럼 쓰면 명시적으로 변환할 수 있어요.

String(123);        // "123"
Number("123");      // 123
Number("안녕");     // NaN
Boolean(0);         // false
Boolean("false");   // true

parseInt("12px", 10); // 12
parseFloat("3.14원"); // 3.14

Number()는 문자열 전체가 숫자여야 숫자로 바뀌어요. 일부 숫자만 읽고 싶을 땐 parseInt()나 parseFloat()를 사용합니다.

실행 결과

    자동 변환은 조심하기

    연산자가 상황에 따라 타입을 자동으로 바꾸기도 합니다. 의도를 분명히 하려면 직접 변환하는 편이 좋아요.

    "5" + 2; // "52" : +는 문자열 연결이 될 수 있어요.
"5" - 2; // 3    : -는 숫자 연산을 위해 변환해요.
Number(null);      // 0
Number(undefined); // NaN
